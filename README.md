# g4kakau.github.io

個人的物理與數學教育部落格，建立在 [**Chirpy**][chirpy] Jekyll 主題上。

## 網站內容

涵蓋：
- **高中物理**：力學、靜力學、電磁學基礎
- **大學數學**：微積分、線性代數、複變
- **應用物理**：天體力學、連續力學、現代物理

每篇文章都包含完整推導、圖示與習題式範例，適合自學與教學參考。

## 本地開發

詳見 [DEV_NOTES.md](DEV_NOTES.md)（繁體中文）

快速開始：
```bash
rbenv install 3.3.6
cd ~/Projects/g4kakau.github.io
bundle install
bundle exec jekyll serve
```

預設在 `http://localhost:4000`。
